=========================================================
   MULAI DISINI - ANDROID PORTABLE KIT v1.1
   Nonton & upload video TikTok / Instagram / SnackVideo /
   YouTube langsung dari Windows, tanpa install apapun
=========================================================

KEBUTUHAN:
- Windows 10 / 11 (64-bit)
- RAM minimal 8 GB (disarankan)
- Ruang disk kosong minimal 12 GB

=========================================================
CARA PALING GAMPANG - MODE OFFLINE (GAK BUTUH INTERNET)
=========================================================

[1] Buka halaman Releases repo ini di GitHub.
    Download SEMUA file yang ada di rilis terbaru:
      - AndroidPortableKit.zip        (program utama)
      - Runtime-QEMU-ADB.zip          (mesin virtual + ADB)
      - BlissOS16-GApps.iso.part01, part02, dst (ISO Android + Play Store)
    Taruh SEMUA file di SATU folder yang sama.

[2] Klik dua kali AndroidPortableKit.zip -> Extract All
    (atau klik kanan -> Extract). Hasil extract jadi folder kit.

[3] PINDAHKAN file-file ini ke DALAM folder hasil extract:
      Runtime-QEMU-ADB.zip
      android-base.qcow2.part01, part02, dst.

[4] Jalankan: 1-Siapkan-Offline.bat
    -> merakit semuanya jadi satu. GAK BUTUH INTERNET.
    (file ISO terpecah tadi digabung otomatis, lalu kamu diminta
     jalanin 1-Setup-Awal.bat SEKALI buat install Android ke disk
     virtual - tinggal pilih 'Auto Install', TETAP TANPA INTERNET)

[5] Jalankan: 2-Buka-Launcher.bat
    -> Klik "JALANKAN ANDROID"

[6] Di dalam Android: login akun Google, buka Play Store,
    install TikTok, Instagram, SnackVideo, YouTube.

[7] UPLOAD VIDEO:
    - Klik "KIRIM VIDEO DARI PC" -> pilih video kamu
    - Video muncul di galeri Android
    - Buka TikTok/IG/SnackVideo/YT -> tombol (+) -> pilih video
      -> tulis caption/judul -> POST!

[8] MULTI-AKUN (CLONE):
    - Klik "+ Profile Baru" (misal: Akun-2)
    - Jalankan barengan beberapa profile, tiap profile akun terpisah

=========================================================
ALTERNATIF - MODE ONLINE (kalau gak mau download file gede)
=========================================================
[1] Extract AndroidPortableKit.zip ke path tanpa spasi, mis. C:\AndroidPortable
[2] Jalankan 1-Setup-Awal.bat (download otomatis ~2.6 GB dari internet)
[3] Ikuti petunjuk install di jendela yang muncul
[4] Lanjut langkah 5-8 di atas.

TIPS PENTING:
- Ekstrak ke path TANPA SPASI (contoh: C:\AndroidPortable) biar mulus
- Biar kenceng: aktifkan "Windows Hypervisor Platform" di Windows Features
- Bebasin mouse dari jendela Android: Ctrl+Alt+G
- Detail lengkap + troubleshooting: PANDUAN-LENGKAP.txt
